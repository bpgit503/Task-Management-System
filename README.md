TaskFlow is a robust and user-friendly task management system built with Spring Boot and JWT authentication, designed to help users efficiently manage their tasks, set priorities, and track progress.

✨ Features
✅ Task Management – Create, edit, and delete tasks with ease
✅ User Authentication – Secure login and registration using JWT & Spring Security
✅ Role-Based Access Control – Manage different user roles with restricted access
✅ Task Prioritization – Assign priority levels to stay focused on important tasks
✅ Due Dates & Reminders – Keep track of deadlines with built-in validation
✅ Activity Logging – Monitor task updates and changes

🛠️ Tech Stack
🔹 Backend: Spring Boot, Spring Web, Spring Security, Spring Data JPA
🔹 Database: MySQL
🔹 Authentication: JWT (JSON Web Token)
🔹 Development Tools: Spring Boot DevTools, Lombok, Validation
🔹 Hosting: Docker / AWS / Heroku (depending on deployment choice)

🎯 Why I Built This
TaskFlow is part of my portfolio to demonstrate my expertise in Spring Boot development, secure authentication, and efficient data management with JPA and MySQL. The project is designed with scalability and best practices in mind, making it an ideal showcase of my backend development skills.
